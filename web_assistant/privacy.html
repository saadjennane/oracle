Privacy Policy

El Oracle (iOS app) — Last updated: 2026-04-21

El Oracle is a performance tool for magicians and mentalists. This Privacy Policy explains what data the app handles, where it is sent, and how it is stored. The guiding principle: your data stays on your device or in services you control. The developer does not operate a central server and does not collect, store, or see any user data.

1. Data collected by the developer

None.

El Oracle has no user accounts, no sign-in, no analytics, no advertising SDKs, and no tracking. The developer never receives any data from the app.

2. Data stored locally on your device

  • Presets you create (prediction templates, option labels, stealth input configuration).
  • Routines (ordered sequences of presets).
  • App settings (language, haptic preferences, shortcut name, optional API keys you choose to enter).
  • Optional history of performed sessions.
  • Images you upload to be used as prediction reveals or as screen backgrounds (fake Notes / fake Calculator).

All of the above is stored on your device using Apple’s SharedPreferences and the app’s local file storage. You can wipe everything at any time via iOS Settings → El Oracle → Reset, or by uninstalling the app.

3. iCloud synchronization (optional, user-controlled)

If you are signed in to iCloud on your Apple device, El Oracle can synchronize the data listed above across your own Apple devices using:

  • iCloud Key-Value Store — presets, routines, settings.
  • iCloud private container (iCloud Drive) — bank images referenced by your presets.

This data is stored in your iCloud account only. The developer has no access to it. Apple’s privacy policy applies: apple.com/legal/privacy .

4. Assistant mode (optional)

When you use the “Assistant” input method, the app uses Firebase Realtime Database (via REST) to pass the current choice made on a second device (the assistant’s webapp at oass.app) back to your phone. The following ephemeral data is exchanged:

  • An Assistant ID that you choose or let the app generate.
  • The current round’s choice (e.g. an option index or a free-text value).
  • A timestamp.

Sessions are cleared after the performance completes. This feature is off by default and only activated when you explicitly select “Assistant” as the input method on a preset. If you do not use Assistant mode, no network request is made to Firebase.

5. OpenAI API (optional, user-supplied key)

Two features can send text to OpenAI:

  • AI text transformation inside Confabulation presets.
  • Audio input when you select the AI-assisted speech mode.

Both require you to enter your own OpenAI API key in Settings. Requests are sent directly from your device to api.openai.com under your account. The developer does not proxy or see the traffic. OpenAI’s privacy policy applies: openai.com/policies/privacy-policy . If you do not configure an API key, no request is made.

6. External APIs you configure (optional)

For Confabulation presets you can opt in to fetch live data from third parties you already use:

  • 11z.co (“Inject”)
  • pag.gg (“Elips”)
  • skyhopgame.com (“HighScore”)

The app contacts these endpoints only when you configure them with your own identifier or API key and trigger the related feature. The developer is not affiliated with these services; their respective privacy policies apply.

7. Device permissions

  • Microphone & Speech Recognition — used only while the audio input method is active during a performance.
  • Photo Library — used only to save prediction images to your gallery or to pick an image you want to use as a reveal background. The app does not browse or upload your other photos.

8. Children

The app is intended for professional and amateur magicians and is not directed at children under 13.

9. Changes to this policy

If this policy changes, the “Last updated” date at the top will be revised. Material changes will be announced in the app’s release notes on TestFlight / the App Store.
